Live frame
Set up the Live helper on your Mac one time
  1. Install ffmpeg and Node

    Open Terminal and paste:

    brew install ffmpeg node
  2. Download the helper

    Save it in your Downloads folder.

  3. Start it before you go live

    Leave the Terminal window open while streaming.

    node ~/Downloads/hubze-live-helper.js
  4. Check the connection

    The tag at the top turns blue when it's ready.
